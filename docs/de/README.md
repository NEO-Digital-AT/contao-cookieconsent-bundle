# NEO Cookie Consent – Dokumentation

NEO Cookie Consent zeigt auf jeder Seite einer Contao-Website einen
Cookie-Hinweis und hält Dienste anderer Anbieter zurück, bis der Besucher
einwilligt. Die Dienste werden im Backend gepflegt; Vorlagen für 47 gängige
Dienste füllen Anbieter, Zweck, Cookies und den Datenschutz-Link aus. Ein
täglicher Scan liest die Seiten, ergänzt erkannte Dienste und meldet unbekannte
Adressen.

Die Erweiterung ist ein Hilfsmittel. Ob eine Website die rechtlichen Vorgaben
erfüllt, verantwortet ihr Betreiber.
